# Analise-de-dados-de-compress-o
Durante as atividades no laboratório, lidei com uma máquina universal de ensaios da Intermetric (IM50), para fins de clareza dos dados, era necessário extrair os dados e efetuar o seu tratamento. Esse projeto apresenta um código desenvolvido em python para realizar o tratamento desses dados, automatizando etapas iniciais.
